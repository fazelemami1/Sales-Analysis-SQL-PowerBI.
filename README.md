📊 AdventureWorks Sales BI Project
📌 Project Overview

This project demonstrates an end-to-end Business Intelligence solution built using SQL Server and Power BI, focusing on sales performance analysis and customer concentration risk.

The goal is to move beyond basic reporting and deliver executive-level insights through proper data modeling, ETL logic, and dashboard design.

🎯 Business Questions

The project answers the following key questions:

How are overall sales performing?

Is revenue stable or volatile over time?

Which customers contribute most to revenue?

How concentrated is customer revenue (risk concentration)?

How many customers generate 80% of total sales?

🗂️ Data Source

Dataset: Microsoft AdventureWorksLT (training dataset)

Database: SQL Server (local instance)

Schema: SalesLT

⚠️ Note:
The original dataset contains sales data for a single transaction date.
To enable trend and time-intelligence analysis, simulated dates were created using SQL views (clearly documented and used only for training purposes).

🏗️ Data Modeling (Star Schema)

The BI model follows best-practice star schema design:

Fact Table

vw_FactSales

Grain: One row per sales order line

Measures: Sales amount, quantity, order count

Dimension Tables

vw_DimProduct – product & category analysis

vw_DimCustomer – customer & company-level analysis

vw_DimGeography – location-based analysis

DimDate – date dimension (created in Power BI using DAX)

Simulated Fact

vw_FactSales_Simulated

Distributes sales across months for realistic trend analysis

🔄 ETL & SQL Layer

All ETL logic is implemented using SQL views, not physical tables, to ensure:

Reproducibility

Transparency

Clean separation between source and analytics layers

⚠️ Customer Concentration Risk

A major focus of this project is customer revenue concentration risk.

Key insight example:

80% of total sales are generated by just 8 customers, indicating significant dependency on a small customer base.

This analysis helps leadership:

Identify commercial risk

Prioritize key accounts

Evaluate diversification strategies
